# Image Tools – расширение для Chrome

Всплывающая панель инструментов на любых изображениях: копирование, сохранение, поиск по картинке, распознавание текста – всё в один клик.

![Версия](https://img.shields.io/badge/version-2.0-blue)
![Манифест](https://img.shields.io/badge/manifest-v3-green)
![Лицензия](https://img.shields.io/badge/license-MIT-brightgreen)

## Возможности

- **Быстрые действия с изображениями**  
  📋 Копировать картинку в буфер обмена, 💾 Сохранить, 📁 Сохранить как, 🔗 Копировать ссылку

- **Поиск по картинке**  
  Google Lens, Яндекс.Картинки, IQDB, AliExpress (по URL)

- **Поиск по лицу**  
  Pimeyes, FaceCheck.id, Lenso.ai (метод загрузки)

- **Поиск товаров**  
  Wildberries, AliExpress (загрузка)

- **OCR (распознавание текста)**  
  Яндекс.Переводчик (OCR), Google Переводчик (OCR)

- **Настраиваемая панель**  
  Выбор видимых кнопок, расположение на экране, минимальный размер изображения для активации

- **Контекстное меню**  
  Все действия доступны через правый клик по картинке

- **Настройки для отдельных сайтов**  
  Для каждого домена можно задать свой набор кнопок

- **Локализация**  
  Русский и английский интерфейс (определяется автоматически)

## Установка (для разработчиков)

Расширение пока не опубликовано в Chrome Web Store, поэтому загружается в режиме разработчика:

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourusername/image-tools-extension.git
   1. Откройте Chrome и перейдите на страницу chrome://extensions/
2. Включите Режим разработчика (переключатель в правом верхнем углу)
3. Нажмите Загрузить распакованное расширение и выберите папку с файлами расширения
4. Иконка расширения появится в панели инструментов браузера

Использование

· Наведите мышь на изображение (по умолчанию срабатывает для картинок больше 200px) → появится панель инструментов
· Нажмите нужную кнопку для выполнения действия
· Или кликните правой кнопкой мыши по картинке и выберите действие из контекстного меню
· Откройте popup-меню (клик по иконке расширения) для настройки:
  · Состав отображаемых кнопок
  · Позиция панели и минимальный размер изображения
  · Глобальное или посессионное включение/отключение отдельных сервисов

Настройка

Все параметры хранятся в синхронизируемом хранилище Chrome и применяются на всех устройствах.
Если включить опцию «Отдельные настройки» для конкретного сайта, для него будет использоваться собственная конфигурация (сохраняется локально).

В popup-меню можно:

· Включить или выключить любой из сервисов
· Выбрать положение панели (↖️ ↗️ ↙️ ↘️)
· Задать минимальную ширину/высоту изображения, при которой появляется панель
· Переключаться между русским и английским интерфейсом
```

```
Технические замечания

· Соответствует Manifest V3 – используется сервис-воркер, нет внешнего кода.
· Загрузка изображений на целевые сайты происходит через дополнительный контент-скрипт search-inject.js, который находит поля ввода или зоны для перетаскивания и программно вставляет картинку.
· Все кросс-доменные запросы изображений выполняются в фоновом сервис-воркере, преобразуются в base64 и передаются контент-скрипту или открытой вкладке.
· Панель инструментов — это фиксированный оверлей, скрытый вне наведения на изображение.
```
