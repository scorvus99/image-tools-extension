# Image Tools – расширение для Firefox и Chrome

Всплывающая панель инструментов на любых изображениях: копирование, сохранение, поиск по картинке, перевод текста – всё в один клик.

![Манифест](https://img.shields.io/badge/manifest-v3-brightgreen)
![Лицензия](https://img.shields.io/badge/license-MIT-green)

## Возможности

- **Быстрые действия с изображениями**  
  📋 Копировать картинку в буфер обмена, 💾 Сохранить, 📁 Сохранить как, 🔗 Копировать ссылку

- **Поиск по картинке**  
  Google Lens, Яндекс.Картинки, TinEye, IQDB, SauceNAO, ascii2d, trace.moe

- **Поиск по лицу**  
  Pimeyes, FaceCheck.id, Lenso.ai

- **Поиск товаров**  
  Wildberries, AliExpress (URL и загрузка)

- **Перевод текста на изображении (OCR)**  
  Яндекс.Переводчик, Google Переводчик, в том числе замена оригинала переведённым текстом


## Установка

Расширение пока не опубликовано в Mozilla Add-ons (AMO), поэтому устанавливается как временное или подписанное дополнение.

### Установка в режиме разработчика (временная)

1. Скачайте актуальный релиз и распакуйте архив.
2. Откройте Firefox и перейдите на страницу `about:debugging#/runtime/this-firefox`.
3. Нажмите **Загрузить временное дополнение…** и выберите файл `manifest.json` из папки расширения.
4. Иконка расширения появится на панели инструментов.

## Использование

1. Наведите мышь на изображение (по умолчанию срабатывает для картинок больше 200 px) → появится панель инструментов.
2. Нажмите нужную кнопку для выполнения действия.
3. Или кликните правой кнопкой мыши по картинке и выберите действие из контекстного меню.
4. Откройте popup‑меню (клик по иконке расширения) для настройки:
   - Состав отображаемых кнопок.
   - Позиция панели и минимальный размер изображения.
   - Глобальные или посайтовые настройки.

## Технические замечания

- Соответствует **Manifest V3** и требованиям Firefox для новых дополнений.
- Расширение оптимизировано исключительно под Firefox: удалены API, не поддерживаемые в Firefox (например, `downloads.onDeterminingFilename`). Используются только кросс‑браузерные и специфичные для Firefox методы.
- Загрузка изображений на целевые сайты происходит через дополнительный контент-скрипт `search-inject.js`, который находит поля ввода или зоны для перетаскивания и программно вставляет картинку.
- Все кросс‑доменные запросы изображений выполняются в фоновом скрипте, преобразуются в base64 и передаются контент-скрипту или открытой вкладке.
- Панель инструментов представляет собой фиксированный оверлей, скрытый вне наведения на изображение.
